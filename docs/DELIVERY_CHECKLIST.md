## موارد اتصال واقعی پیش از انتشار عمومی

این موارد به اطلاعات تجاری کارفرما وابسته‌اند و Adapter آماده دارند:

- جایگزینی Mock SMS با ارائه‌دهنده پیامک و کلید API واقعی
- جایگزینی Mock Payment با درگاه بانکی و callback دامنه واقعی
- تعیین دامنه، TLS، secret production و سیاست backup
- زمان‌بندی `process_booking_tasks` روی سرور نهایی
