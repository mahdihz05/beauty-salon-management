# سامانه رزرو و مدیریت آرایشگاه استیچ

محصول کامل فارسی، RTL و واکنش‌گرا برای جستجو و رزرو آنلاین آرایشگاه، مدیریت چندسالن/چندشعبه و مدیریت مرکزی پلتفرم. رابط کاربری بر اساس ۲۷ خروجی Stitch داخل فایل ضمیمه پیاده‌سازی شده است.

## فناوری و معماری

- فرانت‌اند: React 19، TypeScript strict، Vite و TanStack Query
- بک‌اند: Django 5.2، Django REST Framework و JWT
- دیتابیس: SQLite داخل پروژه؛ بدون نیاز به نصب یا اجرای سرور دیتابیس
- پرداخت و پیامک: Provider آزمایشی Mock با معماری قابل تعویض
- مستندات API: OpenAPI و Swagger
- ذخیره تصاویر: فضای محلی با اعتبارسنجی نوع و سقف حجم ۵ مگابایت

## اجرای آماده پروژه

محیط فعلی قبلاً نصب، migrate، seed و build شده است. برای اجرای هم‌زمان دو بخش:

```powershell
.\start-dev.ps1
```

- برنامه: `http://127.0.0.1:5173`
- API: `http://127.0.0.1:8000/api/`
- Swagger: `http://127.0.0.1:8000/api/docs/`
- پنل داخلی Django: `http://127.0.0.1:8000/admin/`

برای آماده‌سازی مجدد روی یک سیستم تازه فقط یک فرمان لازم است:

```powershell
.\setup.ps1
```

این اسکریپت virtualenv، وابستگی‌های Python و Node، migration و داده‌های دمو را خودکار آماده می‌کند. پیش‌نیاز سیستم تازه Python 3.12+ و Node.js 24+ است.

داده نمایشی بزرگ نیز به‌صورت خودکار ساخته می‌شود: بیش از ۱۱۰۰ کاربر، ۵۰ سالن، ۹۰ شعبه، ۷۰۰ خدمت شعبه و ۳۴۰۰ رزرو به‌همراه پرداخت، نظر، اعلان، کیف پول، تخفیف، تسویه و تیکت. فرمان `seed_showcase` تکرارپذیر است و اجرای مجدد داده تکراری ایجاد نمی‌کند.

## قابلیت‌های تحویلی

- احراز هویت OTP، JWT چرخشی، نقش‌ها و دسترسی سطح شعبه
- ثبت و تأیید سالن، شعبه، گالری، خدمات، پرسنل، شیفت و مرخصی
- جستجو، فیلتر، علاقه‌مندی، پروفایل عمومی و نظرات
- موتور رزرو تراکنشی با چند خدمت، آرایشگر واجد شرایط، buffer، grid و Hold ده‌دقیقه‌ای
- پرداخت کامل/بیعانه، تخفیف، لغو ۲۴ ساعته، بازپرداخت کیف پول و تسویه سالن
- تقویم سالن، مدیریت مشتری، پیامک تأیید/لغو/یادآوری و AuditLog
- ثبت نوبت حضوری پذیرش، تیکت پشتیبانی و فضای اختصاصی عملیات مالی
- گزارش درآمد، کارمزد، رزرو، خدمات پرفروش و خروجی CSV فارسی
- پنل مدیریت مرکزی برای سالن‌ها، داده‌های پایه و نظرات

## کارهای زمان‌بندی‌شده

فرمان زیر Holdهای منقضی را آزاد و یادآوری نوبت‌های ۲۴ ساعت آینده را ارسال می‌کند. در محیط عملیاتی آن را هر ۱۵ دقیقه با Task Scheduler یا cron اجرا کنید:

```powershell
backend\.venv\Scripts\python.exe backend\manage.py process_booking_tasks
```

## کنترل کیفیت

```powershell
.\quality-check.ps1
```

این فرمان lint، ۷۲ تست بک‌اند و تست فرانت، type-check، migration drift، بررسی production، اعتبارسنجی OpenAPI، format، build، audit وابستگی‌ها و آزمون واقعی رابط در Microsoft Edge (دسکتاپ و موبایل) را اجرا می‌کند.

## خروجی هاست اشتراکی

برای ساخت ZIP آماده آپلود که build نهایی React را نیز داخل خود دارد:

```powershell
.\build-deployment-package.ps1
```

خروجی در `deployment-build/beauty-salon-shared-host.zip` ساخته می‌شود. مراحل cPanel، Passenger، تنظیم دامنه و نصب production در [راهنمای هاست اشتراکی](docs/SHARED_HOSTING.md) آمده است.

## پیکربندی محیط

راهنمای کاربری در [docs/USER_GUIDE.md](docs/USER_GUIDE.md)، ممیزی نیازمندی‌ها در [docs/REQUIREMENTS_AUDIT.md](docs/REQUIREMENTS_AUDIT.md)، چک‌لیست تحویل در [docs/DELIVERY_CHECKLIST.md](docs/DELIVERY_CHECKLIST.md)، نگاشت طراحی در [docs/DESIGN_MAPPING.md](docs/DESIGN_MAPPING.md) و پیشرفت مرحله‌ای در [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) است.
